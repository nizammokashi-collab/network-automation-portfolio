# Network Automation Portfolio

Python-based network automation projects demonstrating API integration,
device backup workflows, inventory processing, validation, and reporting.

## Projects

### 1. Device Backup Automation
A modular Python project designed to load a device inventory, collect
commands, back up device output, handle failures, and summarize results.

### 2. Device Health and Inventory API
A Python project demonstrating simulated API pagination, retry handling,
device data validation, filtering, sorting, and JSON reporting.

> The API project uses simulated data; it does not connect to a live network API.

## Technologies

- Python
- REST API concepts
- JSON
- Exception handling and logging
- Git and GitHub

## Security

Examples must use sanitized sample data. Never commit credentials,
tokens, private keys, company configurations, or confidential information.
